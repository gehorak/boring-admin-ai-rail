# Public adoption boundary

This package is a small reference distribution, not an autonomous AI agent,
hosted service, or operational control plane. It is suitable for evaluating
the documented `public_rail` contracts locally and for using the packaged
schemas and operational templates as reference material.

It does not include unpublished host-specific rule material, credentials,
memory, archived evidence, provider prompts, private runtime modules,
project-specific workspaces, or authority records. A consuming project remains responsible for
its own governance, authorization, security review, deployment, and release
decisions.

For a public update, change the maintained canonical source, classify the change
explicitly, generate a candidate from an immutable source commit, and run both
the export verification and this package's independent verifier. Publication
requires separate human authorization.
